SpectaDockPin 0.1.0

First release. Keeps the Dock on the display you choose.

  • Stops the Dock from jumping to another display: only the pointer moves and drags on the last row of your other displays are ignored.
  • Brings the Dock back after sleep, unlock or display changes — only when you aren't using the mouse — and checks that it arrived.
  • Hold Option to move the Dock on purpose; it stays until you choose Move Dock Back Now.
  • Pin To any display (main display by default), Pause, Launch at Login, automatic updates.

Quit SpectaDockPin before you turn its permission off.
